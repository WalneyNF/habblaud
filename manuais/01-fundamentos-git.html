O que o Git registra

Git é um sistema de controle de versões distribuído. Ele acompanha alterações em arquivos e registra snapshots chamados commits. O repositório local funciona mesmo sem internet.

Três estados de um arquivo

Working tree: arquivos que você edita. Staging area (index): alterações selecionadas para o próximo commit. Histórico: commits já registrados. Arquivos untracked ainda não são acompanhados.

Primeiros comandos

git status mostra o estado; git diff mostra mudanças não preparadas; git add arquivo seleciona mudanças; git diff --cached mostra o que será registrado; git commit -m "mensagem" cria o registro.

Exercício isolado

Crie uma pasta vazia fora do Habblaud: mkdir git-laboratorio; cd git-laboratorio; git init; crie um arquivo notas.txt; execute git status; git add notas.txt; git commit -m "Primeira anotação"; git log --oneline. Se necessário, configure user.name e user.email somente nesse repositório.

Recuperação sem riscos

git log --oneline permite consultar o histórico. git show HASH exibe um commit. git diff HASH1 HASH2 compara versões. Antes de restaurar, faça backup e entenda se há mudanças não salvas.

Prática de segurança

Nunca inclua .env, tokens ou credenciais no commit. Use .gitignore para arquivos locais. Evite reset --hard e clean -fd enquanto aprende.

Pratique primeiro em uma pasta de laboratório. Antes de alterar branches, confira git status e preserve seus arquivos.
