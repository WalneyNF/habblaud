Manual 19 — Habblaud Geo Intelligence 0.1

Walney Moreira Klein · walneyk@hotmail.com. God's Eye View original: Bilawal Sidhu e Sameh Khamis.

Objetivo

Conectar Habblaud a ferramentas públicas do God's Eye View via protocolo MCP stdio, mantendo ambos os repositórios independentes. Primeira versão: consultas somente de leitura, análise manual por agente e relatório textual. Não há controle remoto do globo nem conversa autônoma entre vários agentes.

Instalação

Instale dependências do fork God's Eye View com npm install na pasta do projeto. Ele exige Node compatível com package.json. Configure as fontes de dados conforme README e execute npm run dev na porta 4173. Se necessário, defina GODS_EYE_ROOT para a pasta do fork antes de iniciar o Habblaud. No laboratório abra /geo-lab.

Uso

Selecione terremotos, incêndios ou lançamentos; clique Consultar. A ponte inicia o servidor MCP local, negocia JSON-RPC e chama uma ferramenta permitida. Confira a resposta. Escolha um provedor IA já configurado e clique Enviar dados ao agente; a segunda etapa consome tokens ou cotas desse provedor e pede consentimento.

Arquitetura

server/geo-bridge.ts: valida entradas, controla ferramentas permitidas, inicia processo MCP, timeout e devolve JSON. community/geo-lab.html: interface e prompts. server/index.ts: registro das rotas. O God's Eye View fornece server/mcp/stdio.js e src/tools/.

Segurança e limites

Acesso apenas de loopback, ferramentas allowlist, limite de registros e tempo de execução. A consulta depende do servidor God's Eye View e de suas fontes, com cotas e licenças próprias. Não use para rastrear pessoas, invadir dispositivos ou inferir posições não publicadas. O resultado de ferramentas externas é tratado como dado não confiável.

Para desenvolvedores

Para adicionar ferramentas, verifique primeiro o nome e o esquema no catálogo MCP e inclua uma entrada validada no backend; não aceite nomes arbitrários fornecidos pelo navegador. Para múltiplos agentes, adicione um orquestrador com histórico por tarefa, custos por provedor, fila, limites e aprovação humana. Para mover o globo, implemente um canal autenticado de comandos de visualização com validação explícita; não confunda URL de compartilhamento com controle do mapa em tempo real.

Testes

Execute npm run typecheck e npm run build no Habblaud. Teste com a instância God's Eye View ativa e com fontes configuradas. Simule falta do servidor, timeout e ferramenta não autorizada. A validação de tipos e o build não substituem o teste real da integração.
