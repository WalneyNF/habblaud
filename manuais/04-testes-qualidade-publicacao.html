Pirâmide de testes

Testes unitários validam funções isoladas; integração verifica componentes juntos; ponta a ponta valida fluxos reais no navegador. Build e typecheck ajudam, mas não substituem execução funcional.

Comandos do Habblaud

Na raiz do projeto: npx vitest run server/agent-review.test.ts; npm run typecheck; npm run build. A interface pode ser verificada depois de iniciar npm run dev.

Testes de segurança

Verifique bloqueio de path traversal, arquivos sensíveis, tamanho de entrada, hash desatualizado e ausência de gravação não autorizada. Não use projetos importantes como laboratório.

Checklist de publicação

1. Código revisado. 2. Testes passando. 3. UI verificada. 4. Segredos excluídos. 5. Manual atualizado. 6. Limitações registradas. 7. Aprovação do responsável. 8. Merge e release.

Bug report

Registre sistema operacional, branch, commit, passos para reproduzir, resultado esperado, resultado observado, prints e logs sem segredos.

Exercício

Execute a ferramenta de homologação na pasta manuais e marque os testes manuais. Rode o script de diagnóstico somente leitura indicado no módulo 5.

Pratique primeiro em uma pasta de laboratório. Antes de alterar branches, confira git status e preserve seus arquivos.
