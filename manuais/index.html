Como estudar

Leia os módulos em ordem, faça os exercícios em uma pasta separada e use a ferramenta de homologação para registrar seus testes. A ferramenta HTML funciona sem servidor e não executa comandos nem modifica seu projeto.

Para executar testes automatizados, use o script PowerShell scripts/verificar-habblaud-experimental.ps1 na raiz do projeto.
