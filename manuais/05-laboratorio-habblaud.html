Onde estão os arquivos

Projeto local: D:\xampp2\htdocs\habblaud. Repositório remoto: github.com/WalneyNF/habblaud. A branch de desenvolvimento é feature/ollama-groq.

Comece com segurança

Verifique git status --short antes de executar comandos que modificam o projeto. Não apague alterações não publicadas nem sobrescreva scripts existentes.

Ferramenta de diagnóstico

Execute no PowerShell, na raiz do projeto: powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\verificar-habblaud-experimental.ps1. O script executa verificações e testes sem editar código.

Teste visual

Inicie npm run dev e abra /habblaud-studio na porta informada. Cadastre um workspace descartável, abra um JS, edite o rascunho e verifique o diff. Confira que o arquivo original não foi alterado.

Feedback dos testadores

Distribua o código experimental acompanhado dos manuais e da ferramenta. Peça que testadores enviem os resultados sem segredos. Para colaboração, use Issues ou Pull Requests no GitHub.

IA conversacional

A Sala de Conversas é uma evolução desejada: agentes especializados respondem, explicam projetos e propõem tarefas. Permissões de leitura, escrita e execução devem ser separadas. Não confunda a proposta com função pronta.

Pratique primeiro em uma pasta de laboratório. Antes de alterar branches, confira git status e preserve seus arquivos.
