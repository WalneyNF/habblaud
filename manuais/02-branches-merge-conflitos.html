Branch não é uma pasta duplicada

Uma branch é um nome que aponta para uma sequência de commits. A troca de branch modifica o conteúdo da área de trabalho para refletir o commit selecionado.

Criar uma branch de laboratório

Em um repositório de treino limpo: git switch -c feature/minha-experiencia. Faça uma mudança, git add e git commit. Volte com git switch main (ou master, conforme o nome da branch principal).

Merge e Pull Request

Merge integra históricos. Pull Request é a solicitação de revisão hospedada no GitHub; não equivale a merge automático. Faça testes e peça aprovação antes de integrar na principal.

Conflitos

Um conflito ocorre quando o Git não consegue reconciliar automaticamente mudanças. Abra os arquivos com marcadores <<<<<<<, ======= e >>>>>>>, escolha o conteúdo correto, teste e marque a resolução com git add. Nunca aceite automaticamente sem ler.

Estratégia do Habblaud

main representa a linha principal; feature/ollama-groq é a linha experimental. As novidades só passam para main após revisão, testes e aprovação explícita.

Exercício

No repositório de treino, crie duas branches que alteram a mesma linha de notas.txt, faça commits e tente integrar. Observe o conflito, resolva e confira git log --graph --oneline --all.

Pratique primeiro em uma pasta de laboratório. Antes de alterar branches, confira git status e preserve seus arquivos.
