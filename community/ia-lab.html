Configurações · Provedores

Selecione um provedor existente para editar ou cadastre um novo serviço compatível com a API OpenAI. Os modelos são informados pelo identificador oficial.

O teste do Ollama é gratuito e consulta os modelos locais. Para APIs externas, o teste faz uma chamada real e pode consumir sua cota ou gerar cobrança.

Proteção das chaves: esta interface não recebe nem grava a API key. Coloque a chave no arquivo .env local e reinicie o servidor. A chave nunca é enviada ao navegador; ela é transmitida somente ao provedor escolhido durante a chamada de API. Confira a política de dados de cada provedor antes de enviar conteúdo confidencial.
